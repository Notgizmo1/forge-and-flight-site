Individual Capability Units

Fielded Systems

Five integrated capability lines available as standalone units or as a coordinated fleet. Each system is NDAA §889 compliant and designed for operation without commercial cloud dependency.

SOVEREIGN

Airborne Mission Director

DoD Only ITAR

Mission Effect

Coordinated multi-node fleet command and autonomous threat response. Operates in communications-degraded and denied environments. Compatible with Group 2 and Group 3 platforms.

C-UAS Autonomous Multi-Node Fleet Group 2/3 Compatible

NEMESIS

C-UAS Intercept Software

DoD Only ITAR

Mission Effect

Autonomous intercept decision and terminal engagement software. Platform-agnostic — licensable to any qualified interceptor platform. NIST SP 800-171 aligned. Proprietary License.

C-UAS Software Platform-Agnostic Licensable SBIR Eligible

KESTREL

C-UAS Interceptor Platform

DoD Only ITAR

Mission Effect

Fixed-wing kinetic defeat platform. VTOL launch, high-speed intercept profile. GPS-denied capable. Zero RF emissions in terminal phase. American-manufactured.

Kinetic Defeat Fixed-Wing GPS-Denied VTOL Launch

SCOUT

ISR Verification Node

DoD Only ITAR

Mission Effect

Persistent ISR and threat verification node. Multi-track EO/IR detection with real-time track reporting to SOVEREIGN mission director. ADS-B deconfliction native.

ISR EO/IR SOVEREIGN Node Group 1 Platform

WRAITH

Passive RF / Direction Finding

DoD Only Domestic Use Only

Mission Effect

Passive RF spectrum monitoring and direction finding. Available in airborne payload and handheld configurations. Real-time threat cueing to mission director and ATAK. No active emissions — undetectable during operation.

Passive RF Direction Finding ATAK Native Airborne + Handheld Domestic Use Only
